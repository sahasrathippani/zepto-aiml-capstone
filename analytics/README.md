# Module 2 — Analytics Pipeline

This folder implements the Titanic analytics and predictive-modeling module.

## Important design

The raw Titanic dataset is loaded from Seaborn **exactly once** in `01_eda.py`:

```python
sns.load_dataset("titanic")
```

Immediately after loading, it is saved as:

```text
titanic.csv
```

The modeling stage in `02_modeling.py` reads that committed CSV with:

```python
pd.read_csv("titanic.csv")
```

It does **not** call `sns.load_dataset()` again.

## Setup

Open PowerShell in this folder:

```powershell
pip install -r requirements.txt
```

## Run

Run the EDA stage first:

```powershell
python 01_eda.py
```

The first run needs internet access because Seaborn's loader downloads the Titanic dataset.

Then run modeling:

```powershell
python 02_modeling.py
```

## What is covered

### Part A

- `info`, `describe`, `shape`
- missing percentages
- threshold-based missing-value handling
- age/fare histograms and boxplots
- IQR outlier counts
- fare mean, median, mode and skewness
- survival by sex
- survival by passenger class
- survival by sex + class using boolean/grouped analysis
- exactly six columns in the correlation matrix
- correlation heatmap and top two absolute correlations
- more than four charts with written interpretations
- exploratory z-score standardization of age and fare

### Part B

- stratified train/test split before preprocessing
- train-only imputation, one-hot encoding and StandardScaler
- Logistic Regression
- Decision Tree
- Random Forest
- confusion matrices
- accuracy, precision, recall, F1, ROC/AUC
- decision-tree visualization
- baseline vs balanced class weights vs SMOTE
- SMOTE only on the training fold
- Random Forest GridSearchCV
- Random Forest OOB score with `oob_score=True`
- multivariate linear regression for fare
- MAE, RMSE, R² and Adjusted R²
- residual plot and heteroscedasticity statement
- saved complete preprocessing + model pipeline using joblib
- reload and prediction check
